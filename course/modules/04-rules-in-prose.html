Rules Written in Prose

How a Markdown file steers the judge, and the mini-quest that asks you to edit it

A note on the fridge for the house-sitter

You leave a note for a house-sitter who does not read full sentences. They skim for a few magic words: see "strenger" and they get strict, see "Nederlands" and they speak Dutch, see "max 80 woorden" and they keep it short. Everything else on the note is decoration to them.

That note is instructions.md, a plain Markdown file. The house-sitter is loadJudgeRule.

instructions.md 
## Judge / reduce (mini-quest hook — edit this section)
You are the **rechter** (judge). Produce:
1. A short final answer (max 80 woorden, Nederlands tenzij de gebruiker Engels vraagt).
2. Per-member agreement scores from 0 to 1 (how well each member supports the final answer).

### Judge rule (edit for mini-quest)
Wees strenger bij vage claims. Prefer concrete statements. If members disagree, say so explicitly and lower agreement scores for vague answers.
PLAIN ENGLISH

A heading marking the part you are allowed to edit.

Contains "rechter": the quest script checks this word exists.

"max 80 woorden" sets the word limit. "Nederlands" switches the answer to Dutch.

Describes the scores. Human-readable only; the code ignores it.

The quest's target zone.

"strenger" (stricter) is the switch that turns on the harsh 0.35 vagueness penalty.

The house-sitter, in code

loadJudgeRule reads the whole note and returns three settings. Watch the \b markers: they mean "word boundary", so the word must stand on its own.

src/council.ts 
export function loadJudgeRule(instructions: string): { strict: boolean; dutch: boolean; maxWords: number } {
  const strict = /\bstrenger\b|\bbe strict\b|strict-vague/i.test(instructions);
  const dutch = /nederlands/i.test(instructions);
  const maxMatch = instructions.match(/max\s*(\d+)\s*woord/i);
  const maxWords = maxMatch ? Number(maxMatch[1]) : 80;
  return { strict, dutch, maxWords };
}
PLAIN ENGLISH

Take the note's full text; return three settings: strict yes/no, Dutch yes/no, and a word limit.

Strict if the note contains the standalone word "strenger", the phrase "be strict", or "strict-vague". Capital letters do not matter.

Dutch if "nederlands" appears anywhere at all.

Look for "max", a number, then "woord". Remember the number.

Found one? Use it. Otherwise default to 80 words.

Hand the three settings back.

Done.

💡
Prose as configuration

The same file is a system prompt for a real model (module 5) and a config file for the fixture judge. That is elegant, but keyword matching is brittle: a rephrasing a human reads as identical can flip a setting in code. When you ask an AI to "read settings from a prompt file", ask it to list which exact words it matches.
